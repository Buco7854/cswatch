# Working on cswatch

Start with `docs/HANDOFF.md` for current state and `docs/product/WORK.md` for the active task. Read the relevant part of `docs/product/BRIEF.md`, `docs/ARCHITECTURE.md`, `docs/STATUS.md`, and `SECURITY.md` before changing that area. Preserve factual feature status. The user chose TypeScript throughout, CPU-only hosting, S2V asset preparation, Docker behind their own reverse proxy, advanced review controls, mobile/TV/desktop, and dark/light themes. Never reintroduce a Python backend or a bundled TLS proxy.

## Map of the code

- `backend/src/server.ts`: composition, route access policy, streaming uploads, static app/assets.
- `backend/src/auth.ts`, `security.ts`: accounts, Steam OpenID, sessions, origin/CSRF, persistent rate limits.
- `backend/src/providers.ts`: fixed-origin FACEIT adapters and Steam discovery. Credentials remain server-only.
- `backend/src/db.ts`: SQLite store and schema. Transactions are synchronous; never await inside one.
- `backend/src/ingestion.ts`: quotas, storage paths, magic validation, ownership.
- `backend/src/worker.ts`: durable queue, disposable child lifetime, retention.
- `backend/src/parser.ts`: native demoparser adapter and bounded decompression. Never import native parsing into HTTP handlers.
- `backend/src/parser-job.ts`, `backend/native/parser-sandbox.c`: required Linux Landlock/seccomp boundary, job lifetime and bounded scratch polling. Native code is untrusted; never grant the parser database/provider/other-demo access or silently fall back to unsandboxed parsing.
- `backend/src/replay.ts`: bounded version 2 chunk writer and validation of untrusted native artifacts before publication.
- `backend/src/communications.ts`, `voice-packets.ts`: bounded recorded media extraction and Steam/Opus framing. `transcription-worker.ts`, `captions.ts`, `transcription-job.ts`, `transcription.ts`: independent durable CPU subtitles, leases, output validation and offline inference. Keep primary replay ready on speech failure; never enable remote model/audio services as a fallback.
- `backend/src/remote-download.ts`: DNS-pinned approved provider imports. No scraping, arbitrary client URLs or public signed download URLs. External HLTV files use normal uploads; no catalog wrapper.
- `shared/playback.d.ts`: browser/worker replay contract; version every incompatible change.
- `frontend/src/components/PublicSite.tsx`, `Brand.tsx`, `ReviewPreview.tsx`, `PublicProofs.tsx`: public narrative and real, labeled practice interactions. `main.tsx` selects public/workspace/private entry shells.
- `frontend/src/i18n.ts`, `locales/*.json`: EN/FR message/locale policy. Add both languages and run `npm run check:locales`.
- `frontend/src/components/Viewer.tsx`: timeline/controller; `Scene.tsx`: WebGL rendering; `TacticalPlot.tsx`: 2D fallback; `ViewerOptions.tsx`: device-local display preferences.
- `frontend/src/viewer-layout.css`: sole viewer shell and responsive density rules; `viewer-presentation.css`: shared viewer/dialog/portal palette and visibility transitions. Keep instrument geometry in its component CSS. Do not reintroduce competing viewer rules in member.css, member-controls.css, styles.css or workspace.css.
- `frontend/src/useViewerChrome.ts`: scene tap/gesture discrimination, playback idle fade and focus-safe visibility; subtitles remain independent.
- `frontend/src/playback.ts`: pure seeking/frame lookup/skip logic. Keep this independent of Three.js.
- `frontend/src/review-moments.ts`, `components/ReviewFeed.tsx`, `ReviewActions.tsx`: indexed combat/throw navigation, per-player recent moments and progressive round list. `review-prompts.ts` remains the sole identity-safe throw/detonation association; `utility-state.ts`: recorded projectile interpolation and analytical utility effects. Never treat a chunk’s final trajectory point as a landing.
- `frontend/src/replay-cache.ts`, `useReplay.ts`: bounded chunk caching, buffering and identity-safe loading. Whole-match navigation must use manifest bounds, not current chunk bounds.
- `frontend/src/review-events.ts`, `timeline.ts`, `components/ReplayTimeline.tsx`, `RoundEvents.tsx`: recorded event identity, time projection/clusters, shared seek axis and detailed review. Match real players by string Steam ID, never nickname; event markers never use evenly spaced fake time.
- `backend/src/match-state.ts`, `parser-fields.ts`, `shared/match-state.d.ts`, `shared/throw-input.d.ts`: bounded global native state/input evidence and optional controller counters. `frontend/src/match-stats.ts`, `MatchScore.tsx`, `Scoreboard.tsx` consume recorded values; event coverage never establishes pre-recording match totals. See `docs/REPLAY-METADATA.md`.
- `backend/src/objectives.ts`, `frontend/src/objective-state.ts`, `components/ObjectiveHud.tsx`: recorded C4 server clocks and seek-safe lifecycle. Never infer a fuse/defuse duration from a default or future explosion event; preserve elapsed fallback and explicit outcomes.
- `shared/equipment-icons.json`, `backend/src/equipment-assets.ts`, `frontend/src/equipment-icons.ts`, `components/EquipmentGlyph.tsx`: fixed operator artwork registry, bounded validated PNG delivery and local-only loading. No arbitrary URLs, raw SVG serving or game artwork in Git/images. Build copies the registry into backend/dist for Docker.
- `frontend/src/components/ReviewHud.tsx`, `PlayerInputs.tsx`, `MatchEconomy.tsx`: optional recorded inputs/economy. `Communications.tsx`, `voice-playback.ts`: local voice decoding, subtitles/chat, bounded scheduling and identity-safe lifecycle. Missing inputs/communications stay unavailable; physical bindings cannot be inferred.
- `frontend/src/components/WorkspaceShell.tsx`, `AccountMenu.tsx`, `Controls.tsx`: work navigation, account destinations, accessible fullscreen/dialog-aware menus/selects. `/account/connections` is canonical; preserve `/connections` redirects.

- `tools/transcription`: pinned offline model preparation and public speech verification. Models/audio remain under ignored `var/`; use `CSWATCH_TRANSCRIPTION_TEST_MODEL` to exercise actual English/French/kernel inference instead of accepting intentional skips.

## Commands

`npm ci` at root, then `npm ci --prefix backend`, `npm ci --prefix frontend`; optional tools with `npm ci --prefix tools/assets`. `npm run build`; `node scripts/fetch-test-demo.mjs`; `npm test`; `npm run test:assets`; `node scripts/runtime-smoke.mjs`; `npm run test:e2e`; private variants via `E2E_PRIVATE=1 E2E_REGISTRATIONS=false|true`; `npm run check:locales`; `npm run format:check`. See README for same-origin local server/worker and CLI account provisioning. Use Node 24, Linux Landlock ABI3+ and a C compiler/libc headers for the sandbox build. Native tests require the pinned fixture; missing fixtures are skips, never passes. Docker CI executes the same upload/sandbox/chunk smoke in the hardened image.

## Invariants

- All demo files private by default; public access does not imply public ownership. Read routes use `accessDemo`; mutations require ownership. Notes are user-private even on public demos.
- Environment values override admin policy. Empty/unset flags permit UI management. No secrets in browser config, logs, fixtures, or Git.
- Unsafe methods require exact request Origin; authenticated mutations require CSRF. Steam callbacks require state-cookie binding, one-use state, signed field checks, and server verification at the fixed Steam endpoint.
- Never infer ownership from nicknames or merge users by display name/email. Provider/subject pairs are unique.
- File paths derive from random IDs, not filenames. Reserve quotas atomically before streaming. Bound file size, decompression, native process time, and prepared output.
- Worker has no network in Compose. Parser subprocess gets a stripped environment and required kernel filesystem/process/network restrictions. Unsupported confinement fails closed. Scratch polling does not replace host disk quotas; read SECURITY.md before changing parsing.
- Replay Steam IDs remain strings. Source coordinates are inches, Z-up. S2V already exports meters/Y-up; do not apply Source scale twice. Viewer world is `(X,Z,-Y) * .0254`; S2V glTF rotates +90° around Y.
- Use recorded event/flag data for skip controls and round-event markers. Synthetic sample data is labeled and never mixed into personal history. Premier/Competitive/Wingman files use the CS2 upload pipeline; Steam OpenID alone is not demo-download authorization.
- Use shared viewer-presentation.css theme tokens across all viewer surfaces. Keep spectator controls at the edges; no centered input panel or floating equipment toolbar. CT/T split across the two edges on wide/tall screens by default (blue/orange-red); narrow/short screens use one right-side stack, with an optional right-only preference. Keep identities, equipment and health/armor in separate normal-flow rows, without role banners or duplicate selected-player cards. Full inventory lives in the Players drawer. Roster/input visibility and raw input details belong only in Options; no inline show/hide/collapse widgets. Inputs/mouse diagrams default off; compact timeline configuration lives in More. Center Play on the viewport in a narrower two-row deck and reserve desktop inputs at bottom left. Keep radar, score, objective, feed and roster bounds disjoint; `useReviewLayout` shares measured footprints. Hold Tab opens the scoreboard only from the focused scene, with ordinary Tab elsewhere preserved. Native controller counters alone supply match totals; legacy/missing data stays unknown. Event-bound utility inputs are snapshots unless actual command evidence exists. The playback deck is two 44 px rows with in-line timecodes; compact event targets sit above a clear scrub strip on the same recorded axis. Viewer Options has five horizontal categories and one bounded scrolling panel. Custom crosshairs use validated local geometry shared by preview/POV; recorded player crosshairs are unavailable. useViewerChrome.ts owns tap/H/idle visibility for the complete interface over a full-viewport scene. Distinguish taps from drags/pinches, make faded controls inert, preserve keyboard recovery and ignore typing/native/ARIA dialogs. Captions and optional recorded-moment actions remain visible independently; keep projectile visibility independent of quality/path toggles and honor 2D and current playback speed; moment shortcuts are normal seek/camera navigation, never temporary clips or a back/return flow; the optional round strip starts collapsed on all devices. Preserve keyboard focus outlines while reducing decorative frames.
- Display approximations honestly. Do not claim Source 2 visual parity, native smoke physics, frame-rate guarantees, Steam auto-downloads, or real-device validation without evidence.

## Change process

Use focused modules and pure domain helpers. Avoid large route handlers and duplicate client/server schemas; extract as scope grows. Format with Prettier. Test security boundaries and data contracts, not implementation details. Run meaningful tests once after relevant changes. Update STATUS and VERIFICATION when capabilities/checks change. Don't remove a failing assertion to make tests green. Fix the cause or document an actual upstream limitation.

For UI work, use the design skill's app-screen workflow and inspect rendered production screenshots at desktop/tablet/mobile in both themes. Keep controls keyboard-accessible, touch-sized, named, and grouped into progressive options; honor reduced motion. Handle missing map/model, missing provider credentials, processing failure, no events, no WebGL, and private-instance sign-in states. The prior dark and light admin-template designs were rejected. Follow the current product/brand direction in docs/product; public pages and member workspace need distinct compositions with shared brand tokens.

Do not push, publish, commit proprietary assets, use real production accounts in tests, or send external messages unless specifically authorized. Keep generated data and credentials out of Git. Do not claim Docker or external provider integration was tested if the required runtime/credentials were unavailable.
