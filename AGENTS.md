## Commands

`npm ci` at root, then `npm ci --prefix backend`, `npm ci --prefix frontend`; optional tools with `npm ci --prefix tools/assets`. `npm run build`; `node scripts/fetch-test-demo.mjs`; `npm test`; `npm run test:assets`; `node scripts/runtime-smoke.mjs`; `npm run test:e2e`; private variants via `E2E_PRIVATE=1 E2E_REGISTRATIONS=false|true`; `npm run check:locales`; `npm run format:check`. See README for same-origin local server/worker and CLI account provisioning. Use Node 24, Linux Landlock ABI3+ and a C compiler/libc headers for the sandbox build. Native tests require the pinned fixture; missing fixtures are skips, never passes. Docker CI executes the same upload/sandbox/chunk smoke in the hardened image.

The long-running assets service starts with the normal Compose stack and uses a separately published image. Automatic map acquisition independently defaults off. Update with `docker compose pull web worker assets` followed by `docker compose up -d web worker assets`; explicit names also start it in older profile-based files. Include other enabled services/profiles in both commands. The image contains tooling, not proprietary map artwork. Automatic idle artwork/sound preparation still requires a successful fixed-source inventory refresh, free-space reserve and bounded attempts. Persist only schema-validated inventory phase/code/time/retry/exit diagnostics, clear them on recovery and keep detailed failure data admin-only; never log raw errors, paths, URLs or credentials.

## Invariants

- All demo files private by default; public access does not imply public ownership. Read routes use `accessDemo`; mutations require ownership. Notes are user-private even on public demos.
- Environment values override admin policy. Empty/unset flags permit UI management. No secrets in browser config, logs, fixtures, or Git.
- Unsafe methods require exact request Origin; authenticated mutations require CSRF. Steam callbacks require state-cookie binding, one-use state, signed field checks, and server verification at the fixed Steam endpoint.
- Password work can yield. Before session issuance, require the same current immutable user and credential hash; before changing credentials, synchronously revalidate the initiating session/CSRF and prior hash. UI route cancellation suppresses obsolete presentation/navigation while still reconciling actual server cookie changes with identity and CSRF together.
- Never infer ownership from nicknames or merge users by display name/email. Provider/subject pairs are unique.
- File paths derive from random IDs, not filenames. Reserve quotas atomically before streaming. Bound file size, decompression, native process time, and prepared output.
- Replay and speech workers have no network in Compose. The separate official-assets service has acquisition egress, but conversion requires stage-only Landlock/seccomp and no network/process creation. Neither asset image nor mounts may include app DB/demos/accounts/provider credentials. Parser subprocess gets a stripped environment and required kernel filesystem/process/network restrictions. Unsupported confinement fails closed. Scratch polling does not replace host disk quotas; read SECURITY.md before changing parsing.
- Replay Steam IDs remain strings. Source coordinates are inches, Z-up. S2V already exports meters/Y-up; do not apply Source scale twice. Viewer world is `(X,Z,-Y) * .0254`; S2V glTF rotates +90° around Y.

## Change process

Deferred dialog focus restoration must retain its closing context and yield when the user has already chosen a newer visible focus target. Preserve body, removed-element and inert fallbacks. Use controlled frame ordering to verify races rather than enlarging test deadlines.

Use focused modules and pure domain helpers. Avoid large route handlers and duplicate client/server schemas; extract as scope grows. Format with Prettier. Test security boundaries and data contracts, not implementation details. Run meaningful tests once after relevant changes. Update STATUS and VERIFICATION when capabilities/checks change. Don't remove a failing assertion to make tests green. Fix the cause or document an actual upstream limitation.

For UI work, use the design skill's app-screen workflow and inspect rendered production screenshots at desktop/tablet/mobile in both themes. Keep controls keyboard-accessible, touch-sized, named, and grouped into progressive options; honor reduced motion. Handle missing map/model, missing provider credentials, processing failure, no events, no WebGL, and private-instance sign-in states. The prior dark and light admin-template designs were rejected. Follow the current product/brand direction in docs/product; public pages and member workspace need distinct compositions with shared brand tokens.

Do not push, publish, commit proprietary assets, use real production accounts in tests, or send external messages unless specifically authorized. Keep generated data and credentials out of Git. Do not claim Docker or external provider integration was tested if the required runtime/credentials were unavailable. Keep release state in HANDOFF/WORK/STATUS/VERIFICATION current, require the released commit's successful workflow and never inherit earlier passing counts.
