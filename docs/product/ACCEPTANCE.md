# Product acceptance and continuity

The original request is the product scope, not a list to replace during a visual redesign. This matrix records the implemented path and the evidence/remaining dependency. See [active work](WORK.md), [feature status](../STATUS.md) and [verification](../VERIFICATION.md).

| Requirement                                   | Current implementation                                                                                                   | Boundary or remaining evidence                                                                                     |
| --------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------ | ------------------------------------------------------------------------------------------------------------------ |
| TypeScript application; CPU-only host         | Fastify/SQLite, React/Three, disposable native parser worker                                                             | Small compiled Linux sandbox bridge; browser supplies its own GPU or uses 2D                                       |
| `.dem` and `.dem.zst`                         | Private streamed uploads, signatures, quotas, bounded expansion and native parsing                                       | CS2 only; no archives/CS:GO                                                                                        |
| Steam sign-in and connection                  | Verified Steam OpenID immutable identity; local account/link flows; state/nonce/return intent                            | Successful callback covered with a mocked official verifier; real account integration requires operator validation |
| FACEIT connection/import                      | Steam-verified profile, history, approved Downloads API, pinned downloads                                                | Real Data API key and separate approved Downloads token required                                                   |
| Steam match discovery                         | Next-match sharing-code adapter                                                                                          | Game Coordinator demo URL resolution/download/sync remains unimplemented                                           |
| HLTV demo files                               | Download/extract at source, normal private upload with a focused guide                                                   | No HLTV scraper/catalog wrapper                                                                                    |
| Local accounts and extensible auth            | Argon2id, sessions/rotation/revocation, separate provider identities                                                     | Steam is the only current social login; no implicit account merge, MFA or email reset                              |
| Public/private, registrations, provider flags | Environment locks override admin settings                                                                                | Private API/asset gates independent of frontend                                                                    |
| Review viewer                                 | Whole-tab scene, additional fullscreen, cameras/2D, interpolation, players and round/event/timeout navigation            | State is sampled, not Source 2 execution                                                                           |
| Advanced options                              | X-ray, crosshair, radar, killfeed, trails, grenade paths, utility approximations, autoskip, quality                      | Approximate visual effects; no exact smoke physics                                                                 |
| Round review                                  | Events on the actual seek axis, exact cluster selection, round/match zoom and selected-player filters                    | Protocol events and immutable player IDs, not reconstructed guesses                                                |
| Inputs and economy                            | Optional corner mouse/keys, WASD/ZQSD labels, one right-side blue/orange-red roster and explicit phone lineups           | Missing commands stay unknown; no claim of physical bindings or every key press                                    |
| Live bomb objectives                          | Plant/defuse/fuse actor, kit, progress and countdown from recorded state; cancellation and arbitrary seeks               | Unrecorded deadlines show elapsed/unknown timing; no assumed server fuse duration                                  |
| Equipment silhouettes                         | Shared 83-item equipment/review registry, trusted operator SVG-to-PNG preparation and private-safe local raster delivery | Actual game artwork is operator-installed; original schematic fallback when absent                                 |
| Recorded communications                       | Steam/Opus extraction, local voice playback, speaker scope/mutes, chat overlay and transcript                            | Actual Mirage fixture has no voice/chat; synthetic Source 2 protocol and real browser decoding tested              |
| Communication subtitles                       | Independent durable offline CPU Whisper stage, language detection, private timed captions, owner retry                   | Operator model required; actual English/French speech tested; voiced-match corpus validation remains outstanding   |
| Notes and sharing                             | Private timestamp notes; owner-only rename/delete/publish/revoke                                                         | Downloaded copies cannot be recalled                                                                               |
| Long-match delivery                           | Version 2 manifest/chunks, bounded three-slice client cache, prefetch, global bounds/indexes, retry                      | Existing version 1 replays load whole; real-device memory benchmarks still required                                |
| Real Counter-Strike appearance                | Operator S2V exports/GLB optimization/tier discovery; optional animated agents                                           | No proprietary assets bundled; lighting/weapon/animation/audio parity incomplete                                   |
| Desktop/mobile/TV                             | Responsive workspace/viewer; progressive mobile controls, keyboard/remote navigation, 2D/low quality                     | Browser viewport/keyboard checks; no physical S24/TV certification                                                 |
| Dark/light and EN/FR                          | Persisted semantic theme and locale; translated UI/errors/plurals/dates                                                  | Dynamic team/player/file names remain original                                                                     |
| Self-hosted Docker, own proxy                 | Web/worker services, non-root/read-only/capability limits, no Caddy                                                      | Linux Landlock ABI 3+ required; CI exercises hardened image                                                        |
| Public ingestion security                     | Ownership/CSRF/origin, rate limits, reserved quota, required kernel sandbox, output validation                           | Not independently audited; maintain host hard disk/memory quotas and patches                                       |
| Weekly maintenance                            | Monday no-cache base-image refresh, dependency/action update PRs, verification before publish                            | Operators review updates and redeploy; schedule does not replace running instances                                 |
| Agentic continuation                          | Scoped specialist work, explicit contracts/invariants, meaningful regression tests, current handoff and evidence         | Never equate automated design checks with user approval                                                            |

No decorative UI control may stand in for an unfinished capability. Additional provider adapters, native visual parity, actual game assets/device measurements and independent security assessment need their own evidence before status changes.
