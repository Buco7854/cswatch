# cswatch brand direction — replay as an instrument

## Thesis

A competitive Counter-Strike review brand built around **returning to a moment and changing perspective**. The replay chevron and a cut-corner spectator frame form one visual grammar across the wordmark, product media, primary actions, timeline selection and transitions. It should feel like an esports broadcast/review instrument, not a generic admin dashboard or an AI-coaching product.

## System

- **Wordmark/mark:** original angular C/replay monogram plus compact `CSWATCH` lettering. No borrowed game/platform logos as the identity.
- **Display:** Barlow Condensed at strong weight, short purposeful headlines; no arbitrary colored/italic word inside a headline. Compact wordmark may slant as a whole. This replaces the warm consultancy-style type that the random direction draw offered, which contradicts the user's competitive-esports reference.
- **Text/UI:** IBM Plex Sans, locally loaded, clear body and controls. Numbers use tabular figures. Two families total.
- **Color:** graphite/charcoal, off-white, and an ice-teal signal; CT/T hues reserved for actual match data. Light mode uses the same shapes/type/teal signal with neutral white/grey surfaces. No navy/violet, neon glow, glass, decorative gradients or generic lime-on-black.
- **Shape:** square/short-radius work surfaces with one cut corner where the replay motif has meaning; no wall of pill buttons or giant soft cards.
- **Photography/media:** actual product interaction is the proof. Label synthetic practice content. Do not bundle competitor screenshots or imply an illustration is a real game render. Real CS2 game assets still require operator preparation.
- **Motion:** a meaningful perspective/round transition, short playback-control feedback, and public-page section rhythm; no scroll hijack, forced preloader or inaccessible animation. Respect reduced motion.

## Public vs product

The logged-out entry is now one compact upload instrument: a modest condensed headline, short privacy/expiry copy and the working file input. No separate marketing narratives or sample CTA. The workspace is denser: match identity, ownership/privacy, readable player/round/event data, and one primary import/review job. The viewer gives the match the room. They share a brand, not the same layout.

## Test of distinctiveness

Cover the wordmark. The short condensed type, replay/cut-frame geometry, ice-teal signal and round/perspective interaction should still look like cswatch. Cover the hero: auth and the viewer should still belong to the same product. If only the color differentiates a screen, it is unfinished.
