# Native world cutover

**One frame owner.** Give the viewer an imperative compositor that owns the replay clock, input, camera and invalidation. React mounts controls, publishes settings and subscribes to coarse UI events. Playback, scrubbing, entity changes, camera motion, resize and completed mip uploads request frames. Dispose workers, fences, buffers and targets on map change or context loss. Match the native Source camera to the three.js actor camera through one inches/Z-up transform.

**Shared depth and light.** Let three.js own one WebGL2 context and a linear RGBA16F render target with a sampleable depth texture. Bind the target through the renderer, then submit the native sky and opaque/cutout ranges into its active framebuffer. Clear sky depth before the playable world. Reset three.js state at each raw GL boundary and explicitly rebind the target and viewport. Render opaque actors and equipment against that depth, sampling the exported volume and sun-shadow atlases. Render actor shadows from the sun into a small shadow map and sample it on native receivers. Snapshot opaque depth for smoke to avoid framebuffer feedback. Sort glass, smoke and tracers with explicit depth-test/write rules. Draw x-ray silhouettes using scene depth and composite the POV rig with its own projection and cleared/private depth. Run the map exposure, LUT and bloom once over the composed HDR image. Project accessible labels last using the same camera and occlusion result.

**Queries and publication.** Build a triangle BVH from decoded ranges for follow-camera sweeps, feet, label occlusion and wall-impact sounds. Retain surface material, entity ID and visibility, refit moving doors on seek, and exclude sky. Compare against recorded contacts before substituting VRF physics hulls for movement traces. The asset supervisor pins .NET 11.0.100 and verified VRF 21.1, launches read-only extraction and Node packing as separate confined, networkless children, and limits CPU, RSS, time, output and temporary disk. Validate every hash, decoded extent and Brotli sibling, then atomically publish an immutable generation. Bind readiness, removal and demo-authorized file serving to that generation. Regenerate installed map tiers from approved sources and preserve operator-owned files.
