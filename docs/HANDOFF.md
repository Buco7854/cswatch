# Current handoff

- **Replay and state.** The parser writes a version 3 manifest and bounded chunks. Start with an empty SQLite data directory for a fresh instance. Startup validates the schema before using an existing database, and operators retain custody of source recordings, databases and prepared assets. [Replay metadata](REPLAY-METADATA.md)
- **Map preparation.** The isolated assets worker publishes immutable, fully validated packs with SHA-bound model and texture plans. Automatic acquisition is off by default. Prefer a unique approved source and disclose latest-official selection when eligible. Keep manual assets and approval evidence under operator control. [Map assets](MAP-ASSETS.md)
- **Viewer.** Finished demos open at the first recorded live round in POV and use the 73.74° world lens by default. Wide views start with both teams’ cards, a larger radar, an inline round review and direct transport. Auto chooses the map tier from the active WebGL context before loading geometry. One graded output pipeline composites the world, sky and POV. Missing authored grades use the neutral grade, and unavailable float targets use the hardware recovery path. Smoke uses one volume pass with analytic density when journal data is missing. The automatic worker prepares the 101-clip directional agent bank, HUD icons and alternating static and first-person equipment. Prepared map and presentation outputs carry a preparer revision. Missing player models use capsules. Third-person equipment uses weapon-frame packs on posed characters, and player sun shadows use a depth target separate from the static map. [Renderer](product/NATIVE-RENDERER.md)
- **Review evidence.** Demo-time aim, combat feedback, grenade paths, smoke, sound and equipment depend on recorded coverage and bounded preparation. Incomplete native projectile coverage uses independently recorded trajectories. The labeled practice scene stays separate from demos. [Verification](VERIFICATION.md)
- **Providers.** Steam sign-in and linking use OpenID. Match sync needs the operator's Steam Web API key and an encryption key file, plus each member's own game authentication code and a match sharing code. Steam offers no documented demo download, so each synced match opens in CS2 and pairs with a private upload. FACEIT is a match and demo source through the linked Steam ID, and downloads need FACEIT's approval. Live credentialed checks are pending. [Setup](ACCESS-SETUP.md#steam-and-faceit)
- **Release.** Verify the exact source revision and both images before publishing. Keep CPU-only hosting, networkless parser and speech workers, private-by-default access, and keyboard and touch operation in English and French. [Security](../SECURITY.md)
