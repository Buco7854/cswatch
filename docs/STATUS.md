## Deployment and limits

Docker/Compose runs TypeScript services behind the operator's reverse proxy, without Caddy. The default image is `ghcr.io/buco7854/cswatch:latest` with `CSWATCH_IMAGE` override. Weekly rebuild/publication and dependency-update workflows exist, including the separately published `assets` image target. The normal Compose stack starts this isolated worker by default; existing profile-based deployments can explicitly target `assets` when updating. Both release images passed their hardened checks and published in runtime workflow `44482972828`. Docker was unavailable locally; CI supplies the container evidence.

[Automatic official map preparation](product/MAP-ACQUISITION.md) remains behind `AUTO_OFFICIAL_MAPS_ENABLED` (default off, environment override/admin policy) and a running isolated `assets` service. Prefer a unique operator-approved source. Otherwise safe non-addon recordings may use current worker-observed official map membership. A terminal unavailable historical source can select latest; integrity failures do not silently switch. Fixed anonymous Steam app 730/depot 2347770 metadata refreshes hourly without downloading the game. Each request pins the manifest and file SHA-1/size; downloaded content gets SHA-256 and a distinct immutable pack ID. Newly shipped official map names need no code whitelist or historical catalog entry. Owner/guest authorization, Origin/CSRF, rates and bounded deduplication remain. No arbitrary URL or uploaded-map conversion exists.

Administration distinguishes disabled policy, absent worker, missing/stale inventory and optional historical catalog state. Safe fixed phase/code/retry diagnostics explain failed inventory startup without exposing native output, paths or secrets. Viewer bootstrap polling is bounded and read-only; it can submit one eligible request after readiness recovers, but never automatically retries a failed conversion. The actual cause of the user-reported inventory failure is not yet observed.

The dedicated worker has no app database, recordings or provider/account credentials. S2V/Node conversions require stage-only Landlock/seccomp confinement; complete validated packs publish under immutable pack IDs with no-replace rename. A durable three-attempt generation budget bounds crash recovery. Eligible transient failures permit an explicit owner retry after 300 seconds; source mismatches/removed approvals stay terminal. Browser cleanup does not cancel shared preparation, and failed jobs are never automatically retried by the viewer.

Latest packs are visibly labeled and warn that the layout may differ from the recording. Progressive details retain raw recorded header evidence, selected Steam manifest, inventory check time and prepared digest. Verified snapshots remain immutable across inventory updates. Manual packs stay explicitly `version-unverified` when automatic matching is disabled. Catalog matching is operator provenance, not cryptographic proof of original geometry. Complete historical resolution, automatic historical approvals and Workshop/custom maps remain unsupported. Live current-depot metadata discovery passed; complete conversion of a new current-source map is not demonstrated on this disk-constrained host.

Do not claim Source 2 engine execution or exact visual/gameplay parity, complete baked lighting/materials/animation/audio mixing, native smoke/fire simulation, automatic Steam demo sync, FACEIT social login, video/clip exports, MFA/recovery, independent security certification or multi-host scaling. Real Galaxy S24/TV performance, live external-provider integration and wider asset/voice quality need separate evidence. CPU-only hosting does not imply low memory use.
